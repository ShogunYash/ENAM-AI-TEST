# GPT-6 · Research home

**Keep:** Ticker search, the company name beside its symbol, and one tap to the cited verdict. The INFY detail gets the important part right: “1.5–3% → 1–2%” beside “Cut” tells me what changed. Put the verdict summary on the company row so I know which report to open.

**Cut:** The two ticker strips repeat companies, and opening INFY by default makes me scan its financials before I have chosen a stock. Keep the financial tiles inside the report. On the list, lead with misses and revisions before pending items; read counts from the report.

**Default:** **Ready reports** (the planned Pre-built tab) on the first visit; remember the last tab afterwards. As an investor, I can go straight to a management promise and its evidence without waiting for a new report.

| Where | Exact wording |
|---|---|
| Search | Search any NSE ticker |
| Tabs | My portfolio · Watchlist · Ready reports |
| Saved report with verdicts | Guidance reviewed |
| Financial snapshot, no verdicts | Financials only |
| No report checked yet | Build report |
| No search matches | No matching companies |
| No saved reports | No reports ready yet |
| Reviewed calls, no explicit target | No guidance found |

Use “Financials only” only when financials are actually available. “No guidance found” applies only after reviewing the calls.

**Partial report, when transcripts could not be retrieved:** “The financials are available, but earnings-call transcripts were unavailable on this server, so management’s guidance hasn’t been assessed.” Show it above the financials; if the gap was quota exhaustion or only some calls were missing, show that specific gap instead.
